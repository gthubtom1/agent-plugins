# LAB 常用语

使用 Pi 官方扩展接口，兼容 Pi Web 与终端 Pi。可在仓库根目录运行 `pi install ./plugins/pi/lab`，或将插件目录复制到 `~/.pi/agent/extensions/lab/`；两种方式选一种，避免重复加载。已有会话执行 `/reload` 后加载，新会话自动加载。

- 输入 `/lab` 或 `/LAB`，或点击 Pi Web 底栏的「常用」。
- 选择「＋ 新增常用语」，在多行编辑框输入内容，点击「提交」后立即保存并返回列表。
- 点击列表中的常用语，弹窗关闭，将 `lab:` 加在原文前面填入主输入框。比如 `12345678` 会变成 `lab:12345678`，不会自动发送。
- 「✎ 修改常用语」会打开带原文的编辑框，提交保存，取消保留原文。
- 「× 删除常用语」允许选择条目，确认后删除。
- 常用语按添加顺序排列在前面，新条目追加到已有条目之后。「新增、修改、删除」三个管理入口始终排在所有常用语之后。
- 使用弹窗自带的「取消」或 Esc 退出，不再提供重复的「关闭」条目。
- 条目超出弹窗高度时，Pi Web 原生列表可以滚动；三个管理入口也随列表滚动，位于列表末尾。官方 `select` 接口不能把其中几行单独固定在可视区域底部。
- 「新增常用语」入口一直保留，可以持续添加；不同项目、会话共享同一份常用语。

Pi Web 的原生编辑弹窗仅在点击「提交」时返回文本给扩展，不提供逐字输入回调。因此这里是提交后保存；关闭或取消编辑框不会保存未提交的改动。终端 Pi 按其编辑框的确认快捷键保存。

数据存储在 `~/.pi/agent/lab/phrases.json`。如设置了 `PI_CODING_AGENT_DIR`，则使用该目录下的 `lab/phrases.json`。程序与用户数据分开存放，备份整个 `lab` 数据目录即可。JSON 示例：

```json
{
  "version": 1,
  "phrases": [
    { "id": "独立条目ID", "text": "12345678" }
  ]
}
```

采用临时文件写入后替换，读取错误不会用空列表覆盖原文件。多个 Pi Web 会话修改时先读取最新文件，并拒绝覆盖在另一窗口已修改的条目。独立 Pi 进程之间不提供文件锁。

运行测试：在本插件目录执行 `npm test`，无需安装依赖。测试覆盖持久化、注入文本、多行、修改、取消、删除、空输入和错误文件保护。已在 Pi Web 0.18.0 / Pi 1.6.0 中实测底栏入口、新增保存、重新打开读取、填入输入框及删除。
