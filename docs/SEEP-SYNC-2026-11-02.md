## 安装兼容

根仓库仍显式加载原有六个通用扩展。三个通用小包补充显式 `pi.extensions`，避免新增 helper 被错误当入口扫描。
完整 Seep 已经通过自身安装流程部署这些能力；**不要再安装根包或可选包造成重复扩展**。
换机部署 Seep 仍读取 Seep README 和安装器，不能把这个插件备份当作整套工作台。

没有更改第三方插件、技能备份、DSH、其他宿主、活动 Pi settings 或远程访问配置；没有重启 Pi Web。
Seep 既有 vendoring 来源记录保持历史真实性，不为本次回流倒改旧来源提交。

## 复验与入口

使用 Node 24.20.0 和已安装的 Pi SDK 1.4.0，测试在合成目录进行，不读取真实会话或模型凭据。

```powershell
$env:PI_SDK_DIR = '<已安装的 pi-coding-agent 包目录>'
node scripts/test.mjs
node plugins/pi/cmd-guard/smoke-cmd-guard.mjs
node scripts/test-sdk.mjs $env:PI_SDK_DIR --standalone
node scripts/test-sdk.mjs $env:PI_SDK_DIR
node scripts/verify-seep-sync.mjs --seep-root '<Seep 源码根目录>'
```

- 单元及插件行为：76/76。
- 通用守卫冒烟：33/33。测试工具链使用临时文档，不依赖个人目录。
- 通用提示词 + persona/rewind 真实 SDK：62/62。
- Seep 提示词 + persona/rewind 真实 SDK：62/62。
- SDK 检查还验证根包六入口、可选包十入口能加载，无加载错误；两个组合均无模型网络调用、无越界私密文件读取。
- Seep 专用备份 22 个源码文件和主仓库逐字节一致；五个通用共享 helper 一致。
- 另检查第三方/其他宿主未被改动、文档链接、相对导入、JSON 与 `git diff --check`。

SDK 覆盖 cached/every-turn、两种加载顺序、工具续轮、默认/切换/关闭、压缩、回退、重开会话、写入失败、规则更新/删除和原文/图片保留。
旧注入测试中“删除对话内人格字面文本”的预期已替换为“不改历史材料”的回归，不保留错误的擦除行为。
旧 prompt 冒烟入口写死个人机器 SDK 路径，现改成参数/环境变量并复用隔离验收。
二维码可选依赖本次未安装：缺失时 null 回退与矩阵渲染通过，未宣称重新验证真实扫码、Tailscale 或真实远程连接。
